# its chaos

**English** · [简体中文](./README.zh-CN.md)

A Skill from **its** by **oragment**.

Upstream of **its shape**.

For when there is too much material to start with — many notes, scraps, and thoughts, and no clear place to begin.

## What it does

Reduces overload until a small set of fragments is ready for Connect.

It points out visible signals (repetition, tension, recurrence), lets you choose a small starting set, and holds the rest in Later.

Default aim: **3–5 fragments**, but no fixed quota — once the set is startable, it stops.

Then it hands off to **its shape** to begin Connect.

## What it does not do

It does not organize everything, rank fragments by importance, find your theme, or create a Work.

Which fragments matter is your decision.

## Use when

- you have too many fragments
- you cannot see where to begin
- you keep trying to organize everything first

If you have almost nothing yet, use **its empty**.  
If you already have a small workable set, use **its shape**.

## Install

Copy or clone this folder into a supported skills directory, for example in Cursor:

- Project: `.cursor/skills/its-chaos/`
- Personal: `~/.cursor/skills/its-chaos/`

Then ask the agent to use **its chaos**, or invoke it through your environment's Skill interface.

The skill instructions live in [`SKILL.md`](./SKILL.md).

## Related

- **its shape** — main path: Connect → Mainline → Structure → Work
- **its empty** — almost no material; produce first fragments
- **its tight** — material exists, but thinking is stuck

empty / chaos / tight are upstream state Skills. **its shape** is where material takes form.
