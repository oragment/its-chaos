# its chaos

[English](./README.md) · **简体中文**

来自 **its** by **oragment** 的 Skill。

是 **its shape** 的上游。

适合材料太多、无从下手的时候——笔记、碎片、念头很多，却不知道从哪里开始。

## 它做什么

chaos 负责减载与选苗，直到材料足以进入 shape。

它指出可见的信号（重复、张力、反复出现），让你选出一小组起始碎片，其余暂存到 Later。

默认目标：**3–5 个碎片**，但不是硬配额——够开始 Connect 就停止。

然后交给 **its shape**，从 Connect 开始。

## 它不做什么

不整理全部材料，不按重要性排序，不帮你找主题，也不生成 Work。

哪些碎片重要，由你决定。

## 适用场景

- 碎片太多
- 看不清从哪里开始
- 总想先把一切整理好

如果几乎还没有材料，请用 **its empty**。  
如果已经有一小组可用碎片，请用 **its shape**。

## 安装

将本文件夹复制或克隆到支持的 skills 目录，例如在 Cursor 中：

- 项目级：`.cursor/skills/its-chaos/`
- 个人级：`~/.cursor/skills/its-chaos/`

然后让 agent 使用 **its chaos**，或通过当前环境的 Skill 接口调用。

Skill 说明见 [`SKILL.md`](./SKILL.md)。

## 相关

- **its shape** — 主流程：Connect → Mainline → Structure → Work
- **its empty** — 几乎没有材料；产生第一批碎片
- **its tight** — 有材料，但思路卡住

empty / chaos / tight 都是上游状态 Skill。**its shape** 才是材料成形的地方。
